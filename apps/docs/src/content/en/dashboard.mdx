# Dashboard

The Dashboard is your central hub — a real-time snapshot of your business health across all modules.

## Overview

When you open JoyOne, the Dashboard is the first screen you see. It aggregates key metrics from Orders, Tasks, Bookings, Customers, and more into a single view.

## Key Widgets

### Business Summary
- **Revenue today / this week / this month** — total sales figures
- **New orders** — count and trend vs previous period
- **New customers** — acquisition rate at a glance

### Task Summary
- Tasks due today
- Overdue tasks by assignee
- Completion rate for the current sprint or period

### Booking Overview
- Upcoming appointments for today and tomorrow
- Available time slots
- No-show and cancellation rate

### Quick Actions
From the Dashboard you can jump directly to:
- Create a new order
- Add a customer
- Schedule an appointment
- Send a message

## Customization

<Callout type="info">
  Dashboard widgets can be reordered and toggled by each user individually. Settings are saved per user, not per workspace.
</Callout>

Drag and drop widgets to rearrange them. Click the **⚙ Customize** button (top right) to show or hide specific panels.

## Permissions

| Role | Access |
|---|---|
| Owner / Admin | Full dashboard with all data |
| Manager | Department-scoped metrics |
| Staff | Personal tasks and upcoming bookings only |

## Tips

- Use the **date range picker** (top right) to compare different periods.
- Pin your most-used shortcuts in the Quick Actions bar.
- The dashboard auto-refreshes every 60 seconds; click the refresh icon to force-update.
